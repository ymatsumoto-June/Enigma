# Enigma Maker（暗号文メーカー）

ブラウザ上で動作する、簡易的な暗号化・復号化ツールです。テキストエリアに文章を入力すると、選択した暗号方式でその場（クライアントサイド）で変換されます。サーバーへの通信は行いません。

## 主な機能

- **対応する暗号方式**
  - **オリジナル**：各文字の文字コードに文字列長を加算／減算する独自の変換
  - **シーザー暗号**：アルファベットを3文字分シフト
  - **ROT13**：アルファベットを13文字分シフト
  - **ヴィジュネル暗号**：入力した鍵（アルファベット）を使った多表式換字
- **暗号化 ⇔ 復号化の切り替え**：チェックボックスで動作方向（暗号化する／復号化する）と、左右テキストエリアの入力・出力を切り替え可能
- **お問い合わせフォーム**（`form.html`）：氏名・職業・追加してほしい暗号・意見を送信するフォーム画面（送信処理は未実装）

## 画面構成

| ファイル | 内容 |
| --- | --- |
| `src/main/webapp/index.html` | メイン画面（初期実装） |
| `src/main/webapp/index2.html` | メイン画面（`changeAction()` に処理を共通化するなど、ロジックをリファクタリングした版） |
| `src/main/webapp/form.html` | お問い合わせフォーム |
| `src/main/webapp/css/style.css` | 全画面共通のスタイル（黒背景＋グリーン系のターミナル風デザイン） |

`index.html` と `index2.html` は見た目・機能はほぼ同一で、`index2.html` の方が暗号方式ごとの分岐処理を関数・オブジェクトにまとめ、コードの重複を減らした実装になっています。

## 使い方

1. `src/main/webapp/index.html`（または `index2.html`）をブラウザで直接開きます。
2. 「暗号リスト」から使いたい暗号方式を選択します。
   - ヴィジュネル暗号を選んだ場合のみ、「暗号鍵を入力」欄が表示されるので鍵となるアルファベットを入力します。
3. 左側のテキストエリアに平文を入力し、「暗号化する」ボタンを押すと右側に変換後の文章が表示されます。
4. 「動作切り替え」のチェックボックスをオンにすると、ボタンが「復号化する」に変わり、右側に入力した暗号文を左側に復号できます。

## 技術構成

- HTML / CSS / JavaScript（Vanilla JS、フレームワーク不使用）
- [Bootstrap 3.3.7](https://getbootstrap.com/docs/3.3/)（CDN経由で読み込み）
- Eclipse のダイナミックWebプロジェクトとして作成されていますが（`.project` / `.classpath` / `web.xml` あり）、Javaのソースコードやサーブレットは含まれておらず、実質的には静的なHTML/CSS/JSのみで完結するフロントエンドのみのアプリケーションです。
